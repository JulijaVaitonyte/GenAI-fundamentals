# Understanding Generative AI

A curated resource library covering language models and assistants, chips, data centres and energy, and the state of AI.

[Visit the resource library](https://julijavaitonyte.github.io/GenAI-fundamentals/)

## Preview

Open `index.html` in a browser. Select a topic to explore its resources. Links open in a new tab.

## Update

1. Edit `resources.json` to change the main heading, introduction, topics and resource links.
2. Edit `template.html` to change the layout and styling. Add local PDFs to `assets/`.
3. Rebuild with Python 3.9 or later (no extra packages needed):

   ```sh
   python3 build.py
   ```

4. Upload the changed files, including `index.html`, to the root of the GitHub repository and commit to `main`. GitHub Pages republishes automatically.
